📦 Creating & Managing Projects
bash
Copy
cargo new my_app            # new binary project
cargo new my_lib --lib      # new library project
cargo new my_app --bin      # new binary (explicit)
cargo new --vcs git my_app  # init git alongside

🔨 Build, Run, Check
bash
Copy
cargo build                 # build project (debug)
cargo build --release       # optimized build for production
cargo run                   # compile + run (debug)
cargo run --release         # compile + run (optimized)
cargo run -- arg1 arg2      # pass args to your binary
cargo check                 # type-check without producing binary (FAST)
cargo clippy                # linter — catch bad patterns (run this often)
cargo fix                   # auto-fix warnings clippy/rustc can fix
cargo fix --allow-dirty     # auto-fix even with uncommitted changes
cargo clean                 # remove target/ folder (free disk space)

🦀 Code Style Quick Reference
rust
Copy
// snake_case for functions and variables
fn calculate_total(items: &[Item]) -> u32 { ... }
let user_count = 0;

// PascalCase for types, traits, enums
struct UserAccount { ... }
enum ConnectionState { ... }
trait Repository { ... }

// UPPER_SNAKE for constants
const MAX_RETRIES: u32 = 5;

// modules: snake_case files
// file: src/user_service.rs  →  mod user_service;

// Prefer &str for args, String for owned
fn greet(name: &str) -> String {
    format!("Hello, {name}")
}

// Use ? for error propagation, not match-everything
fn read_file(path: &str) -> Result<String, io::Error> {
    let content = std::fs::read_to_string(path)?;
    Ok(content)
}

// Prefer iterators over explicit loops
let sum: u32 = (1..=10).filter(|x| x % 2 == 0).sum();

// Use if let / let else for simple patterns
let Some(config) = raw_config else {
    return;
};

// Explicit return types, avoid implicit type inference for public API
pub fn get_count(&self) -> usize {
    self.items.len()
}

// Derive what you need, don't derive everything
#[derive(Debug, Clone)]
struct User {
    id: u32,
    name: String,
}

// Use #[must_use] on important return types
#[must_use]
pub fn calculate_score(points: u32) -> u32 {
    points * 10
}

⚙️ Workspace (Multi-Crate)
toml
Copy
# Root Cargo.toml

    "api",
    "core",
    "cli",
]

bash
Copy
cargo build --workspace         # build all crates
cargo test --workspace          # test all crates
cargo run -p api                # run specific crate
cargo build -p core             # build specific crate

Copy

🚀 Release / Publish
bash
Copy
cargo build --release                # optimized binary
cargo install cargo-edit             # install cargo-add/remove (older Rust)
cargo install cargo-bump             # version management
cargo bump patch                     # 0.1.0 → 0.1.1
cargo publish --dry-run              # test publish to crates.io
cargo publish                        # publish to crates.io
cargo install --path .               # install your binary locally
